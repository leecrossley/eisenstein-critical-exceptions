# Contributing to this result

Ongoing work on this result belongs in [`leecrossley/eisenstein-prime-window-transition`](https://github.com/leecrossley/eisenstein-prime-window-transition/tree/main/results/eisenstein-critical-exceptions). Edit its `results/eisenstein-critical-exceptions/` directory in a branch of that repository and open the pull request there. For a distinct note on the same mathematical question, add a result directory and an entry in the [family index](https://github.com/leecrossley/eisenstein-prime-window-transition/blob/main/RESULTS.md).

Use the [research contribution guide](https://github.com/leecrossley/eisenstein-prime-window-transition/blob/main/AGENTS.md) to choose a different family when the mathematical scope calls for it. Keep the [original releases](https://github.com/leecrossley/eisenstein-critical-exceptions/releases), citation identifiers and verification records available.
